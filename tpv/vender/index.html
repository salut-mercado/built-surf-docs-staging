Vender con el TPV

Disponible en: 🖥️ Desktop · Windows

Abrir el turno de venta

Sección titulada «Abrir el turno de venta»

Entra en Desktop, selecciona la tienda y abre TPV. Antes de empezar, confirma que la impresora y los demás dispositivos necesarios aparecen conectados.

Crear el carrito

Sección titulada «Crear el carrito»
  1. Escanea un código de barras o busca el producto.
  2. Repite para añadir unidades o cambia la cantidad en la línea.
  3. Para un artículo sin ficha, usa VARIOS, escribe una descripción comprensible e introduce el precio.
  4. Revisa cada línea antes de cobrar. Según la configuración del terminal, podrás editar el total de línea o el precio unitario; en productos a peso solo se puede editar el precio unitario.

Eliminar una línea solo cambia el carrito abierto. Las ventas terminadas conservan sus líneas y datos originales.

Cobrar

Sección titulada «Cobrar»
  1. Pulsa Cobrar y confirma el total.
  2. Selecciona efectivo, tarjeta u otro medio visible.
  3. Si es efectivo, introduce el importe recibido y entrega el cambio indicado.
  4. Espera a la confirmación antes de empezar otra venta.
  5. Entrega el recibo impreso o vuelve a imprimirlo desde la venta.

Salut ERP lo hace automáticamente

Cada línea se redondea por separado. Al terminar, la venta, sus líneas, el pago y el recibo quedan vinculados; el inventario se actualiza y el informe conserva una fotografía de nombres y precios.

Consultar el diario de ventas

Sección titulada «Consultar el diario de ventas»

En el TPV, abre Ventas recientes para consultar el diario de ventas guardado en esta caja para la tienda activa. Se abre con las ventas de hoy.

  1. Usa Hoy, Ayer o el selector de fecha para abrir un día.
  2. Consulta el número de ventas y el total del día. Puedes alternar entre la vista de lista y la de cuadrícula.
  3. Revisa en cada venta la hora, el importe, el medio de pago y el estado de sincronización.
  4. Pulsa Reimprimir cuando necesites otra copia. La caja debe tener un terminal POS vinculado y la impresora disponible.

El diario muestra las ventas locales conservadas en este ordenador, no todo el historial central. Para comprobar ventas de otras cajas o confirmar que una venta ya se sincronizó, usa Ventas, informes y análisis.

Vender a peso

Sección titulada «Vender a peso»

Al seleccionar un producto a peso se abre siempre la verificación. Si la balanza está disponible, coloca un solo producto estable y acepta la lectura. Si no está disponible, Salut ERP ofrece la entrada manual; úsala solo como alternativa. Cada captura de peso crea una línea separada, incluso para el mismo SKU. VARIOS a peso sigue el mismo proceso.

Sin conexión

Sección titulada «Sin conexión»

Desktop puede mantener la operativa preparada para interrupciones breves. No cierres la aplicación ni repitas un cobro cuyo resultado sea dudoso. Cuando vuelva la conexión, deja que sincronice y confirma la venta en Informes. Para decidir qué hacer según el mensaje, ve a Solución de problemas.
