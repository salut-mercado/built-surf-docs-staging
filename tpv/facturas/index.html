Facturar una venta

Disponible en: 🖥️ Desktop · Windows para emitir facturas; 🌐 Web y 🖥️ Desktop para gestionar clientes

Salut ERP crea la factura a partir de una venta terminada. Las líneas, los impuestos, el pago y los datos fiscales quedan guardados tal como estaban al emitirla.

Preparar la tienda y la caja

Sección titulada «Preparar la tienda y la caja»

Antes de emitir la primera factura:

  1. Abre la tienda, pulsa el lápiz junto a su nombre y comprueba en el formulario de edición la razón social, el CIF/NIF y la dirección postal.
  2. Confirma que la caja de esa tienda está lista para vender: en Configuración → Hardware → TPV debe aparecer Listo para vender. Si no lo está, no puedes emitir la factura y Crear factura no aparece en las ventas.
  3. Abre el TPV con conexión. Desktop reserva por sí solo los números de factura que usará si después pierde la red.
  4. Pulsa Crear factura en cualquier venta terminada y espera unos segundos antes de cerrar. Así Desktop guarda la lista de clientes para usarla sin conexión. Puedes comprobarlo buscando un cliente conocido.

Abre el TPV con conexión al empezar un año nuevo o si aparece el mensaje Conéctate brevemente para reservar más números de factura. Repite el cuarto paso cuando necesites llevar a la caja los últimos cambios de clientes. Abrir Gestión > Clientes por sí solo no actualiza la lista sin conexión de esa caja.

Mientras la emisión no esté lista, Crear factura no aparece en las ventas terminadas y Salut ERP no muestra ningún mensaje. Si no lo ves, comprueba que usas Desktop, que Configuración → Hardware → TPV muestra Listo para vender y que el TPV tiene números reservados para el año en curso. Abre el TPV con conexión para reservarlos.

Guardar clientes habituales

Sección titulada «Guardar clientes habituales»

Entra en Gestión > Clientes desde Web o Desktop.

Esta pantalla necesita conexión. Aparece en el menú según el acceso de tu cuenta.

  1. Pulsa Añadir cliente.
  2. En Identidad fiscal, completa la Razón social, el Identificador fiscal y el País del identificador fiscal.
  3. En Dirección de facturación, completa la Dirección, línea 1, el Código postal, la Ciudad y el País de la dirección.
  4. En Contacto y notas, añade el correo electrónico, el teléfono o una nota interna si los necesitas. Son opcionales.
  5. Pulsa Guardar.

Los clientes se comparten entre las tiendas de la misma organización. Puedes buscarlos por razón social o identificador fiscal. Para archivar un cliente, abre el menú de acciones de su fila (los tres puntos) y pulsa Archivar. El cliente deja de aparecer en la lista Activo. Para verlo, cambia el filtro Estado a Archivado o Todos. Las facturas anteriores conservan sus datos.

Editar un cliente solo cambia las facturas futuras. Nunca reescribe una factura emitida.

Emitir una factura

Sección titulada «Emitir una factura»

Solo puedes facturar una venta desde la caja que la cobró, y solo mientras aparezca en Ventas recientes. Esa lista muestra los últimos siete días y, además, las ventas anteriores que siguen guardadas en esta caja. Se conservan las ventas con factura, las que aún no se han sincronizado y la venta más reciente de la caja. Así, una factura antigua puede seguir abriéndose para recuperar su PDF o sustituirla. Las demás ventas sincronizadas sin factura se borran del ordenador cuando pasan ese plazo.

  1. En Desktop, abre Ventas recientes desde el TPV.
  2. Cambia la fecha si hace falta y busca la venta terminada.
  3. Pulsa Crear factura.
  4. En Clientes guardados, busca por razón social o identificador fiscal y elige el cliente. Si no está guardado, completa la Identidad fiscal y la Dirección de facturación en o introduce nuevos datos.
  5. Si no eliges un cliente guardado, elige Solo para esta factura (la opción por defecto) o Guardar como cliente.
  6. Revisa en la vista previa el cliente, los artículos de la venta, el IVA, el pago y el total.
  7. Pulsa Emitir factura una sola vez. Si el PDF se guarda, o falla sin conflicto, el diálogo se cierra y la venta muestra el botón Abrir factura. Encima aparece el estado del PDF: PDF archivado si se guardó, o Archivo PDF fallido si no.

Si el PDF choca con un archivo distinto, el diálogo no se cierra y muestra Falló la acción de factura con el texto «La ruta del PDF ya contiene bytes distintos». Con ese texto, la factura ya está emitida, así que no la emitas otra vez. Cierra el diálogo, pulsa el botón de actualizar (flechas circulares) de Ventas recientes y sigue los pasos de Conflicto de PDF más abajo. Si el título es el mismo pero el texto es otro, cierra el diálogo y actualiza Ventas recientes. Si la venta muestra Abrir factura, no la emitas otra vez; si sigue mostrando Crear factura, puedes intentarlo de nuevo cuando hayas hecho lo que indica el mensaje.

La factura recibe un número fiscal propio. Desktop guarda el PDF en la carpeta salut_invoices del Escritorio, dentro de una subcarpeta con el identificador fiscal del cliente sin separadores y en mayúsculas, por ejemplo B12345678 para B-12.345.678. El nombre contiene el número fiscal y el ordinal de sustitución, por ejemplo 2026-T00-000201_1.pdf.

La factura ya está emitida aunque falle el PDF

No vuelvas a crearla. Abre la misma venta y recupera el PDF con las acciones descritas abajo, o contacta con Salut si queda en PDF pendiente.

Trabajar sin conexión

Sección titulada «Trabajar sin conexión»

Puedes emitir sin red si Desktop ya tiene números reservados. También puedes usar los clientes guardados que la caja haya cargado anteriormente o escribir los datos de un cliente nuevo.

La factura queda guardada en ese ordenador y se envía la próxima vez que abras el TPV con conexión. Si no quedan números, abre el TPV con conexión y espera a que aparezca Crear factura en las ventas terminadas.

Abrir o recuperar el PDF

Sección titulada «Abrir o recuperar el PDF»

En Ventas recientes, una venta facturada muestra el botón Abrir factura. Encima aparece su estado de PDF: PDF archivado, Archivo PDF fallido o Conflicto de PDF. Un PDF pendiente no tiene acción de recuperación en la aplicación: si se queda así, contacta con Salut.

Usa el ordenador que emitió la factura

Ventas recientes no descarga facturas desde la nube. Abre el historial, sustituye la factura y recupera su PDF en la misma caja donde se emitió.

En el diálogo Factura de venta puedes:

  • Pulsar Abrir PDF para abrir el archivo guardado.
  • Pulsar Regenerar PDF o Reintentar PDF si el archivo se borró o no se pudo guardar. El diálogo muestra uno de los dos, nunca los dos, y ambos conservan el número de factura.

Si aparece Conflicto de PDF, ya existe un archivo diferente en la ruta prevista. No lo sobrescribas. Muévelo a otra carpeta para conservarlo, vuelve a Abrir factura y pulsa Reintentar PDF.

Corregir los datos del cliente

Sección titulada «Corregir los datos del cliente»

Una factura emitida no se edita. Si el destinatario es incorrecto:

  1. Abre la factura actual desde Ventas recientes con Abrir factura.
  2. Pulsa Crear factura rectificativa. El botón y el diálogo usan ese nombre, pero esta primera versión crea una factura sustitutiva. No es una rectificativa fiscal ni un abono.
  3. Corrige la identidad fiscal o la dirección del cliente.
  4. Revisa la vista previa y pulsa Emitir sustitución. Si aparece Falló la acción de factura con el texto «La ruta del PDF ya contiene bytes distintos», la sustitución ya está emitida: no vuelvas a pulsarlo, porque cada pulsación crea otra con un número fiscal nuevo. Cierra el diálogo, pulsa el botón de actualizar (flechas circulares) de Ventas recientes y sigue los pasos de Conflicto de PDF. Con otro texto, cierra el diálogo, actualiza Ventas recientes y abre la factura. Si en el historial la factura Actual ya tiene los datos corregidos, la sustitución está emitida: no la emitas otra vez. Si no, puedes intentarlo de nuevo.

Salut ERP asigna otro número fiscal y marca la factura anterior como Sustituida en el historial. La factura nueva aparece como Actual. Las líneas y los importes de la venta no cambian.

Para errores de importes, artículos, pagos o impuestos, no uses esta sustitución como corrección. Contacta con Salut antes de hacer otra operación.

Límites de esta primera versión

Sección titulada «Límites de esta primera versión»
  • Cada factura corresponde a una sola venta terminada.
  • Solo Desktop puede emitir, sustituir y archivar el PDF.
  • Salut ERP no envía la factura por correo. Abre el PDF y entrégalo por el canal acordado con el cliente.
  • El PDF se guarda en el ordenador. No se sube como archivo a la nube.

Si una factura no llega a la central, abre el TPV con conexión. Si sigue sin aparecer, contacta con Salut con el número de factura y el nombre de la tienda. Consulta Solución de problemas.
