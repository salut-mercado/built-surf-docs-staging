Products and SKUs

Available in: 🌐 Web · 🖥️ Desktop

A SKU is the specific item you sell and track. It can have a barcode, tax details, and several variations: sizes or packs of the same item.

Use the product library

Section titled “Use the product library”

Search the library first to avoid duplicates and reuse information for products Salut ERP already recognises.

  1. Open SKUs and choose Find in library.
  2. Type part of the product name. The table shows the name, barcode, variations, and VAT. You can sort it by any column.
  3. Check that the result is the product you sell.
  4. Choose Use on the correct product. For a weighed product, you can first type its three-digit produce code in the box marked “000” in its row, next to Use. The code is optional. If you enter one, it must have three digits, or Use stays disabled.

When you choose Use, Salut ERP adds the product to your catalogue as a linked SKU and closes the window. The window does not show products already linked to an active SKU in your catalogue. If you choose Use on a product you had archived, or whose barcode one of your SKUs already uses, Salut ERP links and reactivates that SKU instead of creating another. If you manage SKUs from a registered POS assigned to a store with an assortment, Salut ERP also adds the new SKU to that assortment. Afterwards, find the new SKU in the main list and review its category, variations, and prices before selling it.

If the search does not return the product, choose Create SKU in the window, or close it and choose Create SKU in the list.

What Salut ERP does automatically

A product added from the library keeps its link to the shared record but becomes a SKU in your catalogue. Sales that are already completed do not change when you later edit the product.

Find or create with a scanner

Section titled “Find or create with a scanner”

You can scan a barcode from anywhere on the SKUs list:

  • If the code already belongs to a SKU in your catalogue, Salut ERP replaces the current search with that code and filters the list. Each new scan replaces the previous one.
  • If the code is not in your catalogue and you are online, Salut ERP searches the global library and, if it finds the product, adds the SKU to your catalogue. On a registered POS assigned to a store with an assortment, it also adds the SKU to that assortment. No message appears: scan the code again to show the SKU in the list.
  • If the code is not in the library, Create SKU opens as an item sold by unit, with the barcode already filled in under SKU settings. When offline, Salut ERP skips the library lookup and opens the same form immediately.

Review and assign a price to SKUs added from the library before selling them.

Create a SKU from scratch

Section titled “Create a SKU from scratch”

The form has two panels. The left panel holds the product: image, name, status, how it is sold, VAT, and category. The right panel holds the Cluster prices and SKU settings. Cluster prices are the price lists your stores use: each cluster is one price list.

  1. Open SKUs and choose Create SKU.
  2. Enter an easy-to-recognise name under Display name.
  3. Choose whether it is sold By unit or By weight, pick the VAT rate, and assign a category.
  4. Complete SKU settings according to how the SKU is sold:
    • By unit: enter the barcode on the default variation and add other variations when needed.
    • By weight: enter the three-digit Produce Code, if you use one. Cashiers use it to find the item at the POS. Variations and barcodes are not shown for these SKUs.
  5. If Cluster prices shows price fields, always enter the base retail price first and, when needed, the special price. That price is only for the default variation. For other variations, use Prices in Assortments, prices, and labels.
  6. Add an image if it helps staff recognise the product, then choose Create SKU.

If this device is a registered POS assigned to a store with an assortment, Salut ERP also adds the new SKU to that assortment.

How a SKU is sold, by unit or by weight, is fixed when you create it and cannot be changed later. If you chose wrongly, create the correct SKU instead of reusing the old one.

Assign a category

Section titled “Assign a category”

Open the category picker and type part of the name in Search categories. Each result shows its full path, for example Productos perecederos > Lácteos. You do not need to type accents: “lacteo” finds Lácteos.

Variations: sizes and packs

Section titled “Variations: sizes and packs”

A variation identifies one presentation of the same SKU. Each row has its own number of units and an optional barcode. Variations you add also have a name. In the create form, the default variation has no name field; in the SKU editor it does. For example, a box of 12 can have a different barcode from an individual unit. Entering 12 under Units lets you receive or sell the box without confusing quantities.

To add a variation, choose Add variation and fill in the new row. Each variation has its own price under Prices. A variation without a price does not appear in the POS. When you are online, scanning its barcode makes the POS ask for the price and save it to the store’s price list.

You can also create several 1 unit variations so that different barcodes identify the same SKU. This helps when the product is identical but its packaging varies by market: a Coke Zero with French text and one with Spanish text may have different barcodes, but both can point to the same SKU. Give each variation its barcode and use the variation name to tell them apart. Scanning either code then identifies the same item in Salut ERP.

Retire a variation

Section titled “Retire a variation”

To stop using one variation without archiving the whole SKU, open the editor and choose the archive icon at the end of its row. Its tooltip reads Deprecate. The row is struck through, and on narrow screens it also shows Deprecates on save. To cancel before you save, choose the undo icon on that row, whose tooltip reads Undo. When you choose Save, the variation is archived and the editor closes. When you open the SKU again, the variation appears under Archived variations, a list below the variations. Expand that list to see the archive date. Unlike Archive SKU, which does not wait for Save, the change does not apply until you save.

The default variation has no archive icon. To retire it, archive the SKU. The archived variations list has no actions: when you reactivate the SKU, its archived variations come back.

Weighed products

Section titled “Weighed products”

Mark a product as By weight when you create it. A weighed SKU you create in Salut ERP is weighed and charged by the kilo. Products added from the library keep the sales unit from their library record. This sale method cannot be changed later.

The Produce Code is optional. If you enter one, it must be exactly three digits. It is separate from the barcode.

Edit and archive a SKU

Section titled “Edit and archive a SKU”

To change a SKU, choose the pencil icon on its row. The editor uses the same form as creation.

To stop using a SKU, choose Archive SKU in the editor footer. Archiving also archives its variations, and reactivating the SKU brings them back. If the SKU already has archived variations, Salut ERP asks you to confirm before archiving it, because those come back when you reactivate it too. If you have unsaved changes, Archive SKU is disabled, and the message Save your changes before archiving. appears next to it. Choose Save (or Cancel if you do not want to keep the changes). The editor closes. Reopen the SKU and choose Archive SKU. Only accounts with access to edit the catalogue see the button.

The list shows active SKUs by default. To see archived ones, open More filters and choose Archived under Status. On the SKU list, scanning the barcode of an archived SKU still finds it. To use it again, open it and choose Reactivate SKU.

If something does not fit

Section titled “If something does not fit”
  • Duplicate code: if the form does not close after you choose Create SKU, the barcode, or a weighed product’s Produce Code, may already belong to another SKU, including an archived one. Close the form and scan that barcode on the SKUs list to find it. For a Produce Code, check your weighed products. Choose the scale icon in Item type, then open More filters, choose All under Status, and open each product to see its code.
  • Missing from the library: it may already be in your catalogue, so search the main list. If it is not there either, create it from scratch.
  • Cannot change to weighed: create the correct SKU. Its sale method is fixed at creation.
  • Missing from POS: add it to the store assortment and price it.
