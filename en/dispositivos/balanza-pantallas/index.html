Scale, displays, and payment terminal

Available in: 🖥️ Desktop · Windows

The customer display opens from Desktop in a browser window.

Scale

Section titled “Scale”
  1. Connect the scale to the computer.
  2. Open Settings → Devices → Scale.
  3. Select the port and complete every visible connection field.
  4. Save and check a stable reading with a test product.

Salut ERP maintains one persistent scale connection. When selling by weight, manual entry is offered only as a fallback if the scale is unavailable. Every accepted reading produces a separate line.

Customer display

Section titled “Customer display”

Open Customer display from Desktop, choose the correct physical display, and configure when to show the cart: always, when payment is requested, or when the payment dialogue is closed. Adjust speed, accent theme, and thank-you message, then simulate a sale.

Payment terminal

Section titled “Payment terminal”

In device settings, select the terminal assigned to this POS and test a small amount according to the installation instructions. Do not repeat a payment if you do not know whether it was accepted: check the terminal and sale first.

Tested equipment

These flows are tested with the devices identified by our team. For another model, perform a complete reading, payment, and receipt test. If it does not respond as described, use Send feedback or WhatsApp.

See Troubleshooting if a port disappears, weight does not settle, or the display does not update.
